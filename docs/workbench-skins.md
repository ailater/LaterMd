# 工作台皮肤

Windows、macOS、Linux 共用同一套皮肤预设、选择器和配置格式。在「设置 → 外观 → 工作台皮肤」选择后，标题栏、侧栏、标签、工具栏、编辑区、状态栏及应用弹窗一起换肤。明暗模式单独选择，也可以跟随当前设备的系统设置。系统菜单、原生文件选择框、窗口按钮和字体遵循各平台惯例。

「青竹护眼」采用低饱和绿纸面、深绿色文字，暗色版采用森林绿底与浅绿文字。它与其他九套预设一起随三平台应用分发，升级启动时自动补充新预设，已有皮肤文件不会被覆盖。

## 配置存在哪里

| 平台 | 配置目录 |
|---|---|
| macOS | `~/Library/Application Support/latermd/` |
| Windows | `%APPDATA%\latermd\` |
| Linux | `$XDG_CONFIG_HOME/latermd/`，未设置时为 `~/.config/latermd/` |

- `settings.json` 保存皮肤名称、明暗模式、字号、行距等偏好。
- `themes/*.ron` 保存正文样式及应用的浅色/深色色板。完整皮肤格式为 `(markdown: (...), shell: (light: (...), dark: (...)))`，不包含平台路径。
- 旧版仅含 MarkdownStyle 的 RON 仍可读取；原九套预设按名称补齐应用色板，其他旧自定义皮肤使用默认应用外壳。

## 跨设备使用

目前配置保存在各设备本地，没有账号或云端自动同步。

使用内置皮肤时，在另一设备选择同名皮肤即可。迁移自定义皮肤时，在外观设置中「导出皮肤」，把生成的 `.ron` 文件复制到目标设备配置目录的 `themes/` 下，重启应用后选择它。两端需使用支持整应用皮肤的版本。

如果也要迁移全部外观偏好，可在退出两端应用后，备份目标设备的 `settings.json`，再复制源设备的 `settings.json` 及对应皮肤文件；这会同时替换字号、行距等已有偏好。无需复制文件树、窗口布局或其他包含本机路径的配置。

## 实现与验证

`theme_presets.rs` 提供所有平台共用的预设，`State::load_preferences` 在启动时安装并扫描皮肤，`ThemeSettings::apply` 统一投影到 egui 和正文。macOS 和其他平台的外观页都调用 `settings::skins::choices`，没有仅在 macOS 注册皮肤的分支。

共用测试覆盖预设安装、旧文件不覆盖、RON 色板往返、应用换肤和还原、皮肤卡片点击，以及主要文字、次要文字和选中文字对背景的 4.5:1 对比度。原生控件与字体仍可能因平台而呈现细节差异。
