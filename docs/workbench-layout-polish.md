# 工作台布局精修

本轮按已确认的四项方向落地：侧栏瘦身、缩略图自适应、三栏宽度协调、顶部层级整理。延续现有皮肤、原生窗口按钮和菜单。

## 布局规则

- macOS 侧栏：文件夹选择固定在顶部，文件 / 搜索 / 大纲合为一行；Git 与反向链接从「更多视图」菜单进入。切换视图时仍能切换文件夹。文件树得到更多垂直空间。
- 三平台文档标签横跨源码与预览区域，文件切换明确作用于两栏。标签使用正文底色表示选中，关闭命中区域扩大。
- 标题栏展示工作区名称，标签展示文档名称；状态栏去掉重复文件名，保留保存状态、行列与字数。macOS 搜索框随窗口宽度收缩。
- 源码工具条和预览标题保持同一层级，统一正文区域的顶部内边距。格式命令继续走原有选区通路，兼容最新 Live 工具栏。
- 三平台按 380pt 编辑区预算限制左右栏宽度。最小 900pt 窗口保留可用的格式工具条与正文；用户主动拖动的栏宽持续保存，窗口临时变窄时只压缩显示宽度，放大后恢复原偏好。
- 缩略图新增「自动适应」偏好，默认开启：编辑区至少 600pt 且源码逻辑行数超过两屏时显示。判定使用未添加缩略图的视口宽度，避免来回闪动；长行软换行不计入该阈值。关闭自动适应可手动常显；原有总开关与快捷键继续有效。Live 模式沿用不显示缩略图的行为。

## 平台范围

三栏宽度预算、栏宽恢复、文档标签、状态栏、编辑/预览间距、缩略图行为及配置在三平台共用。macOS 使用紧凑文字导航，Windows/Linux 保留现有活动栏和系统窗口习惯。

## 验证

重点回归窄窗往返恢复栏宽、短文与长文的缩略图显隐、手动常显拖动、标签关闭/切换、常用视图点击与低频工具入口、源码和 Live 格式操作、明暗主题、设置持久化。验收以真实 UI 帧和实际窗口截图为准；Windows/Linux 视觉效果仍需真机复核。
