# 写作、源码与对照预览

## 关系

| 入口 | 用途 | 可编辑 |
|---|---|---|
| 写作（原 Live Preview） | 直接在正文中写，当前段落显示 Markdown，其余段落渲染排版 | 是 |
| 源码 | 检查和编辑完整 Markdown 标记 | 是 |
| 对照预览 | 源码模式右侧的排版参照 | 否 |

顶部只保留「写作｜源码」两个平级模式。对照预览是源码模式的辅助面板，不是第三种编辑模式。写作仍为按块编辑，不承诺完全所见即所得。

## 切换与恢复

- 新安装默认浅色主题、写作模式与大纲侧栏；首次切到源码不自动打开对照预览。
- 三平台导航顺序为大纲、文件、搜索。旧用户保存的主题与侧栏选择继续恢复；打开文件不强制切走正在使用的文件树或搜索结果。
- 旧配置升级默认写作，保留原先的左右栏、栏宽及源码预览偏好。
- 主动选择的编辑模式会在下次启动恢复。
- 写作始终收起右栏。切回源码恢复上次的对照开关；打开/关闭都能记住。
- 在写作中点击对照入口（含菜单或快捷键），进入源码并打开对照。在源码中则切换显隐。
- 禅定保留现有沉浸阅读语义；阅读中选择编辑模式或对照预览会先退出禅定，再执行相应命令。重启不恢复临时禅定态。
- 保存布局时恢复被写作/禅定临时隐藏的面板偏好，不把临时隐藏覆盖成永久选择。
- 点击已经选中的模式无操作。切模式不修改文档、不清空选区或重建编辑缓冲。

两种编辑模式沿用现有 buffer 和撤销行为；写作的撤销仍按活动块分段，本次不改变编辑机制。内部命令 ID `ToggleLivePreview` / `ToggleRightPreview` 与快捷键保持兼容，菜单、快捷键设置和三平台标题栏统一新名称。

## 验证范围

覆盖首次启动、旧 JSON 迁移、两种模式重启、对照开关往返、禅定交互、文本/修订号不变、模式点击路由及文字中心线。实际窗口检查写作、源码、对照和窄窗；Windows/Linux 原生外观仍需真机复核。
