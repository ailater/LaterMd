# macOS 外观重设计

状态：已在 `feature/macos-appearance` 分支落地；此文档保留设计目标与验收口径。

## 现状

当前 macOS 窗口使用无边框跨平台外壳，最小化/最大化/关闭在右侧；36pt 标题栏、菜单栏、文档标签和格式工具条层叠；40pt 图标 rail 同时承载五个视图与六个文件动作。浅色正文标题偏蓝，标签下划线、图标选中条和控件高亮重复强调。现有应用截图已用于本地检查。

## 设计方向

统一目标：让桌面窗口、导航和控件遵循 macOS 阅读与操作习惯，保留现有 Markdown / Live / AI / Git 能力。

- 使用真实系统窗口按钮与系统缩放/全屏行为。通过 eframe `with_decorations(true)`、`with_fullsize_content_view(true)`、`with_title_shown(false)`、`with_titlebar_shown(false)` 实现内容延伸至标题栏，并给左上角窗口按钮预留空间。以实机点击、拖动、全屏验证为准，不能靠画三个圆代替原生按钮。
- 工具栏以文档名为主，常驻只留侧栏、搜索、模式切换、预览和设置。完整命令继续可访问。macOS 使用 AppKit 原生顶部菜单栏，窗口内部不再重复绘制菜单。
- 侧栏采用文字可辨的分组导航，移除重复文件动作列。文件树仍用现有懒加载逻辑，搜索、大纲、Git、反向链接保留。
- 文档标题采用正文中性色，蓝色用于选中、链接与操作。标签用淡底和适度圆角，减少下划线与重复装饰。
- 浅色采用白色内容面、暖灰外壳；深色采用中性炭灰，避免蓝黑大块底色。控件、弹窗、状态栏统一字号层级与间距。
- 保持正文和 UI 字体分工：界面 12–13pt，辅助文字 11pt；文档保留用户字号、行距、皮肤设置与现有 CJK 基线修正。不覆盖用户自定义排版配置。

## 两个比较方向

1. 文档工作台：带文字的侧栏、可见文档标签、源码/预览双栏，适合频繁切换项目与技术文档。
2. 安静写作：紧凑导航、居中限宽的 Live 文档、工具栏更少，适合持续写作。既有功能通过明确入口可达。

## 实施边界与验证

实现限于 `latermd-app` 的 macOS 外壳与默认视觉样式，不修改 vendor、Markdown 解析和缓冲层。保留非 macOS 平台布局，新增 macOS 分支并覆盖消息接线、最小 900×600 窗口、侧栏/预览显隐、模式切换、设置、禅定退出、暗浅主题和拖放打开。

本地六项门禁之后，进行原生窗口关闭/最小化/全屏、拖动/缩放、中文输入候选框和保存恢复的实机验证。设计稿为视觉原型，不是已实现功能。

## 2026-10-10：工具栏与区域边界精修

分支 `feature/macos-toolbar-polish`。沿用已批准的三栏工作台，针对用户标注的标题栏、模式/搜索区与目录选择行调整：

- 标题栏从 52pt 收紧至 40pt；28pt 点击区域配 14–17pt 线性图标，面板按钮改为细线分栏图形，标题前增加文档标识。
- 源码/Live 使用统一的中性分段控件，仅点击另一模式才切换；搜索框改为 28pt 圆角矩形，增加放大镜与清空入口，提示文字改为实际用途「搜索文档…」。
- 文件夹名称、最近目录与「打开文件夹…」合成一个下拉控件，窄侧栏中省略长名称，完整路径保留在悬停提示。
- macOS 工作台的面板边界统一为单物理像素分隔线，保留拖拽边缘高亮；源码底色与文档面一致，移除大片灰色输入框底，预览栏标题改为辅助文字色。
- 自定义控件补充辅助技术语义；搜索与模式切换继续走原有消息通路。旧平台外壳保持原有控件。

在本地基于现有设计实现并截图检查；外部设计迭代未执行（自动审批拒绝源码外传）。

## 2026-10-10：设置、排版与编辑区精修

分支 `feature/macos-preferences-polish`，基于已合入的 #167。

- 界面加载本机 San Francisco，源码与代码块使用 SF Mono；中文优先查找苹方 SC 的实际 face，兼容系统字体资产目录，失败时沿用既有字体回退。字体只从系统读取，不随应用分发。预览和编辑器保留各自的 CJK 行高/基线修正，正文的字号与行距偏好继续生效。
- 状态栏固定单行，以可见字形的中心对齐文字。左侧为文件、存储状态、光标位置和字数，右侧为主题、AI、MCP；窄窗优先省略辅助信息，长文件名截断。
- 设置窗口使用紧凑标题与整行导航，外观页分为主题、文字与排版、写作、文档样式。主题采用可点击的小预览图，写作开关使用明确的标签与说明；所有设置继续走原有消息与持久化通路。底部只保留一条分隔线和关闭入口。
- 文档标签使用 28pt 高度、文档图标、12pt 文件名、小尺寸关闭按钮和中性选中底色；格式工具栏统一 28pt 点击区域与 14–15pt 图标，文字按钮按可见字形居中。标签切换、关闭确认、右键批量操作和格式快捷键不变。
- 源码与 Live 活动块移除输入框式外边框，保留内部文字边距、光标、选区与 IME 通路；工作区保留细线分区。

验证包含系统字体来源和等宽字宽、中文混排排版、状态栏多缩放/窄窗布局、新设置控件消息接线，以及既有标签/编辑/设置测试。明暗主题以本地运行截图复核；设置页像素采样同步修正为遵守 ScrollArea 的 scissor，避免把视口外的卡片误判成覆盖底栏。

## 2026-10-10：整应用皮肤

分支 `feature/macos-overall-skin`。沿用已经确认的 macOS 工作台布局，将原来只控制正文的皮肤升级为全应用外观。

- 设置 → 外观 → 工作台皮肤：提供默认外观与 9 套预设，用实际色板绘制工作台缩略图，点击即时切换。皮肤区放在外观页顶部。每套都有浅色/深色两版，继续支持跟随系统；皮肤选择与明暗模式独立。
- 应用标题栏、侧栏、标签、工具栏、源码/Live/预览、状态栏、设置、关于及弹层统一读取当前 Context 的语义色板。macOS 系统菜单、窗口按钮仍由系统绘制。保留系统字体、布局、密度、字号和行距。
- 新 RON 格式是 `(markdown: (...), shell: (light: (...), dark: (...)))`。导出同时保存正文和完整应用色板，改名或分享后仍保留外观。颜色字段包括 chrome、rail、sidebar、content、text、secondary、hover、selected_bg、accent、border、code_bg 和 faint。
- 旧版 MarkdownStyle RON 继续可读。旧的九套内置预设按原名补齐应用色板，不改写磁盘文件，保留用户正文修改；其他旧自定义文件使用默认应用色板。损坏的完整皮肤报错并跳过，不吞成默认正文。
- 色板变化时才重投影两套 egui Style，并重新应用当前密度，避免切皮肤重置控件尺寸。首帧在完整皮肤恢复后投影，避免自定义皮肤启动闪变。

验收覆盖换肤/还原、两套明暗控件投影、密度与字号保持、旧 RON 兼容、导出改名与重启恢复、缩略图点击，以及九套应用色板主要文字/次文字/选中文字的 4.5:1 对比度。使用隔离配置运行实际窗口，截图检查 Nord 深色与 Rosé Pine 浅色的工作台和设置页。非 vendor 改动。
