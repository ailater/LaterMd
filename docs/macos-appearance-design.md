# macOS 外观重设计

状态：已在 `feature/macos-appearance` 分支落地；此文档保留设计目标与验收口径。

## 现状

当前 macOS 窗口使用无边框跨平台外壳，最小化/最大化/关闭在右侧；36pt 标题栏、菜单栏、文档标签和格式工具条层叠；40pt 图标 rail 同时承载五个视图与六个文件动作。浅色正文标题偏蓝，标签下划线、图标选中条和控件高亮重复强调。现有应用截图已用于本地检查。

## 设计方向

统一目标：让桌面窗口、导航和控件遵循 macOS 阅读与操作习惯，保留现有 Markdown / Live / AI / Git 能力。

- 使用真实系统窗口按钮与系统缩放/全屏行为。通过 eframe `with_decorations(true)`、`with_fullsize_content_view(true)`、`with_title_shown(false)`、`with_titlebar_shown(false)` 实现内容延伸至标题栏，并给左上角窗口按钮预留空间。以实机点击、拖动、全屏验证为准，不能靠画三个圆代替原生按钮。
- 工具栏以文档名为主，常驻只留侧栏、搜索、模式切换、预览和设置。完整命令继续可访问。macOS 使用 AppKit 原生顶部菜单栏，窗口内部不再重复绘制菜单。
- 侧栏采用文字可辨的分组导航，移除重复文件动作列。文件树仍用现有懒加载逻辑，搜索、大纲、Git、反向链接保留。
- 文档标题采用正文中性色，蓝色用于选中、链接与操作。标签用淡底和适度圆角，减少下划线与重复装饰。
- 浅色采用白色内容面、暖灰外壳；深色采用中性炭灰，避免蓝黑大块底色。控件、弹窗、状态栏统一字号层级与间距。
- 保持正文和 UI 字体分工：界面 12–13pt，辅助文字 11pt；文档保留用户字号、行距、皮肤设置与现有 CJK 基线修正。不覆盖用户自定义排版配置。

## 两个比较方向

1. 文档工作台：带文字的侧栏、可见文档标签、源码/预览双栏，适合频繁切换项目与技术文档。
2. 安静写作：紧凑导航、居中限宽的 Live 文档、工具栏更少，适合持续写作。既有功能通过明确入口可达。

## 实施边界与验证

实现限于 `latermd-app` 的 macOS 外壳与默认视觉样式，不修改 vendor、Markdown 解析和缓冲层。保留非 macOS 平台布局，新增 macOS 分支并覆盖消息接线、最小 900×600 窗口、侧栏/预览显隐、模式切换、设置、禅定退出、暗浅主题和拖放打开。

本地六项门禁之后，进行原生窗口关闭/最小化/全屏、拖动/缩放、中文输入候选框和保存恢复的实机验证。设计稿为视觉原型，不是已实现功能。
